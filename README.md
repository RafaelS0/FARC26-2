# FARC26-2

Comandos para executar o código:

- make

- make run

Durante o envio de cada arquivo, o servidor mostra periodicamente no terminal
os bytes enviados, o percentual concluído, a taxa média efetiva em kbps e o
tempo decorrido. Arquivos HTML continuam sem limitação de taxa; os demais
objetos seguem a configuração de QoS. Para imagens, o monitor também informa
o intervalo entre a requisição do HTML e cada requisição de imagem.
